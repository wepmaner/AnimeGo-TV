> [!NOTE]
> Проект не связан с animego.me и его владельцами. Приложение обращается к сайту так же, как его собственные страницы, и работает с вашим аккаунтом.

## Возможности

- **Главный экран** — «Продолжить просмотр» с серией, местом остановки и полоской прогресса; отдельный ряд «Давно не смотрели» (больше 14 дней); жанры; новые серии сезона; онгоинги и ТОП-250.
- **Поиск, каталог и «Мой список»** — сетка постеров с подгрузкой; вкладки списка (Смотрю, Запланировано, Просмотрено, Отложено, Брошено, Пересматриваю).
- **Плеер** — стартует с места, где вы остановились; перемотка ±10 с, при удержании быстрее; плашка с кнопками как на YouTube; ряды сезонов и серий; отсчёт до следующей серии; пропуск опенинга.
- **Озвучки** — запоминаются для каждого тайтла: *основная* и *запасная*, которая включается сама, если основная студия ещё не озвучила новую серию.
- **Качество** — «Авто» (HLS) или фиксированное, запоминается.
- **Прогресс хранится на сайте** — позиция и отметки «просмотрено» уходят на animego.me, на телефоне и ПК видно то же самое. На телевизоре хранятся только куки, выбор озвучек и несколько дат.
- **Вход необязателен** — каталог, поиск и просмотр работают без аккаунта; вход через встроенную экранную QWERTY-клавиатуру.

## Что нужно

- Windows с Git Bash, .NET SDK и workload Tizen для .NET (`Tizen.NET.Sdk`).
- `sdb` из Tizen Studio или tizen-tools (в Git Bash нужен `MSYS_NO_PATHCONV=1`).
- Телевизор Samsung на Tizen в той же сети. Проверено на UE50TU7140 (2020, Tizen 5.5).

## Установка на телевизор

1. **Включите режим разработчика:** откройте *Apps*, наберите на пульте `12345`, переключите *Developer mode* в **On**, в *Host PC IP* укажите IP компьютера и перезагрузите телевизор.
2. **Подключитесь:**
   ```bash
   sdb connect <ip-тв>:26101
   ```
3. **Соберите, установите и запустите:**
   ```bash
   TV=<ip-тв>:26101 scripts/deploy.sh Release
   ```
4. На телевизоре: *Apps* → ⚙ → **AnimeGo** → *Добавить на главный экран*.

Если новый телевизор не принимает `.tpk`, поднимите `api-version` в `src/AnimeGo.Tv/tizen-manifest.xml`. После смены значка поднимите `version` и переустановите приложение (`sdb uninstall ru.animego.tv` — вход в приложении при этом тоже сотрётся).

## Разработка

```bash
dotnet test                               # тесты Core на ПК
node scripts/devlog.mjs                   # приём отладочных строк с ТВ
TV=<ip-тв>:26101 scripts/deploy.sh Debug  # Debug-сборка шлёт DevLog на ПК
```

`DevLog.Host` в `src/AnimeGo.Tv/DevLog.cs` должен указывать на ваш ПК.

**Приватные фикстуры.** `node scripts/login-sample.mjs` входит на сайт с ПК так же, как приложение (логин и пароль спрашивает в консоли), и сохраняет страницу в `tests/AnimeGo.Core.Tests/Fixtures/private/`. Эта папка в `.gitignore`: там имя аккаунта и история просмотра. Тесты, которым она нужна, без неё пропускаются.

## Устройство проекта

| Папка | Что |
|---|---|
| `src/AnimeGo.Core` | Логика без UI (netstandard2.0, без NuGet): HTTP, вход, разбор, модели, правила прогресса |
| `src/AnimeGo.Tv` | Приложение Tizen: экраны, плеер, экранная клавиатура |
| `tests/AnimeGo.Core.Tests` | xUnit-тесты на настоящих ответах сайта (`Fixtures/`) |
| `design/` | Макеты и исходник значка |
| `research/samples` | Исходные ответы сайта, по которым писались парсеры |
| `scripts/` | `deploy.sh`, `devlog.mjs`, `login-sample.mjs` |

## Известные ограничения

- Потоки Kodik не воспроизводятся; используются CVH и AniBoom.
- Родная клавиатура телевизора из приложения работает ненадёжно, поэтому своя.
- Первая загрузка постеров после запуска занимает несколько секунд (WebP декодируется на ТВ), дальше — из кеша.
- Пропуск опенинга пока эвристический; точные тайминги из aniskip — в планах.
